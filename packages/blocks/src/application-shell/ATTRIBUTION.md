# Application Shell 1

Design reference: [Application Shell 1 by Shadcnblocks](https://www.shadcnblocks.com/block/application-shell1).

An original Preact composition of Kamod UI primitives based on the supplied feature
brief and reference layout. No React or Radix runtime code is included. Branding,
demo user data and icons use local fixtures and Kamod's Lucide icon exports.

## Application Shells 2–8

Original Kamod compositions: Inset Workspace, Compact Navigation Rail, Horizontal
Workspace, Right-Hand Navigation, Split Workspace with Inspector, Sectioned Workspace
and Persistent Action Workspace. These reuse
the existing Shell 1 navigation adapters and Kamod primitives. Their numbering
does not identify corresponding ports from an external design collection.
Previews use Kamod UI branding; people and records are fictional local fixtures.

## Application Shell9 — IDE Workspace

Original Preact/Kamod composition informed by the public screenshot and feature
description of [Application Shell9](https://www.shadcnblocks.com/block/application-shell9)
by Shadcnblocks. No Pro source was accessed or included. The file-tree adapter
supports one folder level; the scratch editor and output are local demonstrations,
not an embedded editor engine, filesystem, Git client or terminal.

## Application Shell11 — Video Platform

Original Preact/Kamod composition informed by the public screenshot and feature
description of [Application Shell11](https://www.shadcnblocks.com/block/application-shell11).
No Pro source is included. Media metadata and channel names are fictional local
fixtures; no playback, recommendation or subscription service is implemented.
